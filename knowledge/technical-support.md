# Technical Support and Troubleshooting (Texnik Yordam)

## Official information
- Zynygram AI Support assists users with application usage, errors, media generation issues, and platform features.
- Basic technical troubleshooting steps can be performed by users independently (updating app, checking internet connection, clearing cache).
- Complex technical bugs and service outages are handled by the Zynygram engineering team.

## Procedures
- Troubleshooting common client issues:
  1. Internet connection check: Ensure stable Wi-Fi or mobile data connection.
  2. Cache clearing: Clear application cache in mobile OS settings or browser storage.
  3. App update: Ensure the latest version of the Zynygram client or browser is being used.
  4. Restart application: Force close and reopen the app.
- AI Generation errors (e.g. image/video generation fails):
  - Check prompt complexity or network stability.
  - If generation fails repeatedly, record the exact error message or screenshot and contact human support via `/human`.
- OFFICIAL POLICY REQUIRED: Server status dashboard URL, API endpoints status, and minimum system requirements for devices.

## Frequently asked questions
- **Ilova ochilmayapti yoki qotib qolyapti (App not opening or freezing):**
  Quyidagi bosqichlarni bajarib ko'ring:
  - Internet aloqangizni tekshiring.
  - Ilovani to'liq yopib, qaytadan ishga tushiring.
  - Ilova keshini (cache) tozalang va eng so'nggi versiyaga yangilang.
  - Muammo davom etsa, /human buyrug'i orqali xabar bering.
- **Rasm yoki video generatsiya qilish ishlamayapti (AI generation not working):**
  AI generatsiya tizimida vaqtinchalik yuklama bo'lishi mumkin. Bir necha daqiqadan so'ng qayta urinib ko'ring. Muammo hal bo'lmasa, operatorimizga bog'laning.
